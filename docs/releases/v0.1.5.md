# Emot-ID v0.1.5

Patch release correcting Romanian spelling across model-owned emotion and Body Compass copy.

## Changes

- Corrects the Plutchik compassion result from `compașiune` to standard Romanian `compasiune`.
- Restores Romanian diacritics in 22 legacy Body Compass descriptions and guidance fields,
  including `încleștare`, `împământare`, `respirație`, and `emoțională`.
- Extends one language-quality test across translations, generated synthesis, catalog copy, model
  metadata, body-region data, and somatic display labels.
- Pins `compasiune` exactly and rejects the confirmed malformed spellings without adding a runtime
  dictionary or another production dependency.
- Verifies the rendered trust-plus-sadness Plutchik result in Mobile Safari and Mobile Chrome.
- Keeps internal English IDs, English copy, safety semantics, Google handoff behavior, and
  psychological model behavior unchanged.

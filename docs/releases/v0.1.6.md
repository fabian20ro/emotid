# Emot-ID v0.1.6

Patch release improving screen-reader casing and language semantics for the bilingual interface.

## Changes

- Keeps prose-like screen eyebrows in sentence case so Chrome/TalkBack does not expose Romanian or
  English sentences as acronym-like, character-by-character speech.
- Resolves and applies the stored or browser language before React mounts the first localized
  controls instead of correcting the static English fallback after render.
- Applies runtime language changes to document semantics before rerendering localized content.
- Covers the initial Romanian Today title, primary actions, six quick emotions, section headings,
  and bottom navigation at the first localized DOM mutation in Mobile Safari and Mobile Chrome.
- Documents the tested platform boundary: Emot-ID owns page content and language metadata, while
  Chrome/TalkBack configuration owns synthesized voice selection and AT-generated action hints.
- Keeps copy, emotion models, safety behavior, persistence, Google handoff semantics, styling, and
  outbound network behavior unchanged.

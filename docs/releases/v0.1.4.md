# Emot-ID v0.1.4

Maintenance release preventing contradictory release identities from reaching `main`.

## Changes

- Adds one pure release-consistency validator with deterministic, structured diagnostics.
- Requires package metadata, the lockfile root, README release URL, latest numeric release-note
  filename/title, and maintenance-plan release-scope link to identify the same release.
- Compares semantic versions numerically, so `v0.1.10` correctly follows `v0.1.9`.
- Runs eight fixture tests and the live repository check through `check:policy` and CI.
- Keeps unreleased GitHub tags and releases outside the candidate gate; no network access, duplicate
  release manifest, application runtime code, or product behavior was added.
